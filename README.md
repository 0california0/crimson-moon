# Crimson Moon

A dark VS Code theme with a red and dark red color scheme on a pure black background.

## Installation

1. Open the Extensions view (`Ctrl+Shift+X`)
2. Search for **Crimson Moon**
3. Click **Install**
4. Press `Ctrl+K Ctrl+T` and select **Crimson Moon**
